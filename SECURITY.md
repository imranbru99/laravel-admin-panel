# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security-related issues, please email **me@imrandev.bd** instead of using the public issue tracker. All security vulnerabilities will be promptly investigated and addressed.

Please include:
- A description of the issue.
- Steps to reproduce or proof-of-concept.
- Potential impact and affected versions.

We appreciate your responsible disclosure!
